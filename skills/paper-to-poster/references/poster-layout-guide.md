# Poster layout guide

## 1. Common sizes

| Name | Size | Notes |
|---|---|---|
| A0 | 841 × 1189 mm (33.1 × 46.8 in) | Most common at European and Asian conferences; portrait or landscape |
| A1 | 594 × 841 mm (23.4 × 33.1 in) | Smaller sessions |
| 36 × 48 in | 914 × 1219 mm | Common in North America; often landscape |
| 42 × 56 in, 48 × 72 in | various | Some large meetings |
| Digital e-poster | Screen (often 16:9) | Lower word count; may allow animation |

Always take the size and orientation from the event's instructions.

## 2. Reading behaviour

| Distance | What is read | Design implication |
|---|---|---|
| 3–5 m | Title, headline, one large figure | Must convey the main result alone |
| 1–2 m | Section headings, figures, captions | Captions state findings |
| Close | Text and details | Kept short; the presenter fills in |

## 3. Layouts

| Layout | Use |
|---|---|
| Three columns (landscape) | Classic; reading order clear |
| Two columns (portrait) | A0 portrait |
| Central result | Main figure in the centre column at large size, with supporting blocks around |
| Headline band | A large statement of the finding across the top under the title (the "better poster" style), details in a side column |

Leave 30–40% white space; align blocks to a grid; keep gutters equal.

## 4. Type sizes (A0; scale for other sizes)

| Element | Size |
|---|---|
| Title | 85–120 pt |
| Headline finding | 60–80 pt |
| Section headings | 44–60 pt |
| Body | 28–36 pt |
| Captions and references | 20–24 pt |

Sans-serif body text, left-aligned, short lines (about 40–60 characters per line).

## 5. Content budget

| Block | Words |
|---|---|
| Headline | 10–20 |
| Problem | 40–60 |
| Approach | 40–80 plus a diagram |
| Results | 2–3 figures, each with a finding caption of 15–30 words |
| Conclusions | 3 bullets |
| References, acknowledgements, contact | small |
| Total | about 300–800 |

## 6. Colour and graphics

- One or two accent colours plus neutrals; institutional colours if required.
- Strong text contrast; no text over photographs.
- Colour-blind-safe series colours matching the paper.
- Vector graphics; raster at 150–300 dpi at final printed size.

## 7. LaTeX options

| Class | Notes |
|---|---|
| tikzposter | Block-based layout; themes; good for column layouts |
| beamerposter | Uses Beamer; familiar for Beamer users |
| baposter | Column-based, boxed blocks |

In PowerPoint, set a custom slide size equal to the poster, then design at 100% scale.

## 8. QR code

Link to the paper, code, or a short project page; place it near the conclusions or the title; print a short URL beside it; test scanning from 1 m on the printed proof.

## 9. Print preparation

| Check | |
|---|---|
| PDF at final size, fonts embedded | |
| Images not pixelated at 100% zoom | |
| Bleed added if the printer requires it | |
| A4 proof print readable at arm's length | |
| Names, affiliations, logos correct | |
| Printer turnaround and travel tube or fabric option | |

## 10. Presenting at the poster

Prepare a 30-second summary (problem, idea, result) and a 2-minute version (adds method and the second result). Ask visitors about their interest before choosing which to give.
