# Editing catalogue

## 1. Wordy phrases and replacements

| Wordy | Replace with |
|---|---|
| in order to | to |
| due to the fact that | because |
| in spite of the fact that | although |
| a large number of | many |
| at the present time | now, currently |
| has the ability to | can |
| in the event that | if |
| it is important to note that | (delete; state the point) |
| it can be seen that | (delete; state what is seen) |
| with regard to, with respect to | about, for |
| for the purpose of | for, to |
| the fact that | that (or rephrase) |
| a majority of | most |
| prior to | before |
| subsequent to | after |
| in close proximity to | near |
| is able to | can |
| plays an important role in | affects, determines, contributes to (say which) |

## 2. Nominalisations to verbs

| Nominalised | Verb form |
|---|---|
| performed an analysis of | analysed |
| conducted an investigation of | investigated |
| made a comparison between | compared |
| gave a description of | described |
| reached a conclusion | concluded |
| achieved an improvement in | improved |
| provide an explanation for | explain |
| is in agreement with | agrees with |

## 3. Hedging calibrated to evidence

| Evidence | Wording |
|---|---|
| Strong, replicated | X reduces Y; these results show |
| Good but limited | X appears to reduce Y; the results indicate |
| Preliminary | X may reduce Y; this suggests |
| Speculative | One possible explanation is |

Remove stacked hedges: "might possibly suggest" becomes "suggests". Do not add hedges to established facts, and do not remove hedges the author placed on purpose.

## 4. Register

| Informal | Formal |
|---|---|
| a lot of | many, much, a large |
| get, got | obtain, become, receive (choose the precise verb) |
| big | large, substantial |
| look at | examine |
| find out | determine |
| things | (name them) |
| really, very | (delete or quantify) |
| basically, actually | (delete) |
| don't, can't, it's | do not, cannot, it is |

## 5. Inflated and promotional words

| Word | Plainer choice |
|---|---|
| utilise | use |
| leverage | use, apply |
| facilitate | help, allow |
| novel | new, or describe what is new |
| groundbreaking, revolutionary, remarkable | (delete; let the result speak) |
| cutting-edge, state-of-the-art (as praise) | recent, current best (with a citation) |
| delve into | examine |
| showcase | show |
| robust (without evidence) | (state the test it survived) |
| seamless | (describe the property) |

## 6. Formulaic patterns to break up

| Pattern | Problem | Fix |
|---|---|---|
| Every paragraph opens with "Moreover", "Furthermore", "Additionally" | Mechanical rhythm | Use the logical connector only where the relation needs it |
| Triplets for rhythm ("efficient, scalable, and robust") | Lists that are not all supported | Keep the supported items |
| "Not only X, but also Y" repeated | Formula | State both plainly |
| A closing sentence that restates the paragraph | Repetition | Delete it |
| "In this section, we will discuss" | Announcing instead of saying | Start with the content |
| Uniform sentence length | Monotony | Vary length; keep one idea per sentence |
| Rhetorical questions in technical prose | Informal | State the point |

## 7. Clarity

- Subject and verb close together; avoid long phrases between them.
- Old information at the start of a sentence, new information at the end.
- Name the actor when it matters ("we excluded" rather than "were excluded").
- One term per concept throughout.
- Replace "this" with "this result" or "this method" when the referent is unclear.
- Break sentences over about 30 words that carry more than one idea.

## 8. Mechanics often missed

| Area | Rule |
|---|---|
| Articles | Countable singular nouns need an article: "a model", "the model" |
| Agreement | "The set of results is"; "data are" (or "data is" if the venue's style allows) |
| Tense | Past for what was done; present for what the paper shows and general truths |
| Numbers | Words for one to nine in running text (APA), numerals with units; consistent decimals |
| Abbreviations | Define at first use; not in titles unless universal |
| Hyphenation | Compound modifiers before a noun: "a two-stage model" |
| Lists | Parallel grammatical form |
| Commas | Serial comma per house style |
| Spelling variant | One variant (British or American) throughout |

## 9. What not to change

Technical terms, defined notation, equations, numbers and units, citations, quotations, reference list entries, and the strength of claims. If an edit would change meaning, ask instead.

## 10. Before and after

Before (63 words): "It is important to note that, in order to perform an analysis of the effectiveness of the proposed approach, a large number of experiments were conducted, and it can be seen from the results that our novel method has the ability to significantly outperform the existing state-of-the-art baselines in a robust manner across all of the datasets."

After (25 words): "We evaluated the method on five datasets. It outperformed the strongest baseline on all five (Table 2), by 1.8 to 3.4 points in F1."

The edit removes filler and promotional words and keeps the claim. "Significantly" was replaced by the actual numbers, which the author must confirm from Table 2.
