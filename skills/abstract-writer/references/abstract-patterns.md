# Abstract patterns, word budgets, titles, and keywords

## 1. Forms

| Form | Headings | Common in |
|---|---|---|
| IMRaD structured | Background or Introduction; Methods; Results; Conclusions | Medicine, health, many sciences |
| Objective-led structured | Objective; Design; Setting; Participants; Interventions; Main outcome measures; Results; Conclusions | Clinical journals |
| Purpose-led structured | Purpose; Design/methodology/approach; Findings; Originality/value; Research limitations/implications; Practical implications | Business and management journals (Emerald style) |
| Unstructured single paragraph | none | CS, engineering, humanities, most conferences |
| Graphical abstract | image plus short text | Some chemistry, materials, biology journals |
| Highlights | 3 to 5 bullets with a character limit | Elsevier journals |

Use the journal's exact headings and order.

## 2. Word budgets

| Total | Background and gap | Method | Results | Conclusion |
|---|---|---|---|---|
| 150 | 25–30 | 30–40 | 55–65 | 20–25 |
| 200 | 30–40 | 40–50 | 75–90 | 25–30 |
| 250 | 40–60 | 50–70 | 80–100 | 30–40 |
| 300 | 50–70 | 60–80 | 100–120 | 35–45 |

Results get the largest share. Background is cut first.

## 3. Sentence moves

| Move | Pattern | Example |
|---|---|---|
| Context | <Topic> matters because <reason>. | Insomnia affects about one adult in ten and responds poorly to sleep-hygiene advice. |
| Gap | However, <what is unknown>. | Whether app-delivered CBT works without therapist contact is unclear. |
| Aim | We <tested / developed / examined> <what>. | We tested a fully automated CBT app against a sleep-hygiene leaflet. |
| Method | In <design> of <sample/data>, we <did what> and measured <outcome>. | In a 12-week randomised trial of 180 adults, we measured insomnia severity (ISI). |
| Results | <Finding with numbers and comparison>. | ISI fell by 7.1 points with the app versus 3.2 with the leaflet (difference 3.9, 95% CI 2.6 to 5.2). |
| Conclusion | <What it means, for whom, with a limit>. | Automated CBT may offer a scalable first-line option; longer follow-up is needed. |

## 4. Making results specific

| Vague | Specific |
|---|---|
| significantly improved accuracy | improved accuracy from 81.3% to 84.1% on ImageNet |
| outperforms state-of-the-art methods | reduces error by 12% relative to the best published method on three of four benchmarks |
| was associated with better outcomes | was associated with 30% lower odds of readmission (OR 0.70, 95% CI 0.58 to 0.85) |
| participants reported positive experiences | 11 of 14 participants described the tool as reducing preparation time |

## 5. Cutting words

| Cut | Example |
|---|---|
| Throat-clearing | "In this paper, we", "It is well known that" |
| Nominalisations | "performed an analysis of" → "analysed" |
| Redundant pairs | "each and every", "future plans" |
| Background a specialist reader knows | general statements about the field |
| Method detail | software versions, hyperparameters |
| Hedges stacked | "may potentially suggest" → "suggests" |

## 6. Titles

| Type | Example | Strength |
|---|---|---|
| Descriptive | A randomised trial of app-based CBT for insomnia | Clear about design and topic |
| Declarative (states the result) | App-based CBT reduces insomnia severity more than sleep-hygiene advice | Message in the title; claim must be well supported |
| Question | Can an app replace the therapist in CBT for insomnia? | Engaging; can sound tentative |
| Name plus description | SleepCoach: automated CBT for insomnia at scale | Common in CS; the name must be followed by a description |

Keep titles under about 15 words, put the most important terms first, avoid abbreviations unless universal, and avoid "novel", "new", and "towards" unless the venue's culture expects them.

## 7. Keywords

- Four to six, unless the journal sets a number.
- Do not repeat words from the title; keywords add search terms.
- Use the field's indexing vocabulary: MeSH for biomedicine, ACM CCS for computing, JEL codes for economics, the journal's own list if given.
- Include the method, the population or domain, and the outcome.

## 8. Final checks

| Check | |
|---|---|
| Every number appears in the body with the same value | |
| No undefined abbreviations; no citations unless allowed | |
| No references to figures, tables, or sections | |
| The main limitation appears if it changes how the result is read | |
| Tense: past for what was done and found; present for conclusions | |
| Within the word limit as the venue counts it | |
